⚙️ Panel Editor Soal — Sport 100

Edit pertanyaan, 5 jawaban teratas, poin, dan kata kunci sinonim. Urutan teratas otomatis menjadi jawaban bernilai tertinggi.

Anda bisa langsung mengunduh file sport100-data.json, mengeditnya dengan aplikasi Notepad/VS Code, atau mengimpor file JSON baru.

🎯 Cara Kerja & Konsep Game Sport 100

  • Game ini dirancang untuk dimainkan di proyektor kelas tanpa siswa perlu memegang HP.
  • Guru bertindak sebagai pemandu kuis atau menunjuk perwakilan siswa untuk mengetik jawaban kelompok.
  • Setiap soal berisi 5 kotak jawaban tersembunyi dengan poin menurun dari kotak #1 (tertinggi) hingga #5 (terendah).
  • Jika kelompok menjawab salah, sistem mencatat Strike (maksimal 3 strike sebelum soal berganti).

✏️ Cara Mengedit Soal Tanpa Merubah Kode Web

  1. Cara 1: Lewat Panel Admin Ini
    Cukup buka tab "Daftar & Edit Soal", ketik pertanyaan baru, ubah teks 5 jawaban dan poinnya, lalu klik tombol "Simpan ke Browser" di bawah. Data langsung tersimpan di komputer/laptop Anda!
  2. Cara 2: Lewat File `sport100-data.json`
    Buka folder sport-100/ lalu buka file sport100-data.json dengan Notepad. Anda bisa menambah atau mengganti soal dengan format standar berikut: 
    {
  "question": "Sebutkan nomor lari dalam atletik!",
  "timerSeconds": 60,
  "answers": [
    { "rank": 1, "text": "Lari Sprint", "points": 100, "aliases": ["sprint", "100m"] },
    { "rank": 2, "text": "Lari Estafet", "points": 80, "aliases": ["estafet", "sambung"] },
    { "rank": 3, "text": "Lompat Jauh", "points": 60, "aliases": ["lompat"] },
    { "rank": 4, "text": "Tolak Peluru", "points": 40, "aliases": ["peluru"] },
    { "rank": 5, "text": "Lempar Lembing", "points": 20, "aliases": ["lembing"] }
  ]
}
  3. Fitur Sinonim (Aliases):
    Siswa mungkin menjawab dengan kata yang sedikit berbeda (misal "sepakbola" vs "sepak bola" atau "sprint" vs "lari cepat"). Masukkan variasi kata tersebut pada kolom sinonim dipisah dengan tanda koma agar tebakan siswa tetap dinilai benar!
